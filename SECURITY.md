# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within PedagogyGuard AI, please report it responsibly:

1. **Do NOT** open a public GitHub issue for security vulnerabilities
2. Email the maintainer at [TODO: your email] with details
3. Include steps to reproduce the vulnerability
